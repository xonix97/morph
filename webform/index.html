02 / THE CONTRACT

Not magic.
A boundary.

Morph is honest about what hot reload can guarantee. State lives on the stable side. Behavior lives on the swappable side. The runtime validates the bridge before it lets anything change.

03 / VERIFIED BOUNDARIES

Two real adapters.

Morph is deliberately narrower than “HMR for everything.” Each implemented boundary has a lifecycle, failure behavior, state rule, and reproducible demo.

04 / THE DEVELOPER EXPERIENCE

One command
to keep moving.

Start from a template, wire an explicit boundary, and get a runtime that tells you whether the change was actually applied.

app.py
from morph_runtime import Runtime

runtime = Runtime(["app_logic"])

while runtime.running:
    runtime.state["frame"] += 1
    runtime.call(
        "app_logic", "render", runtime.state
    )
MorphPluginV1 plugin = load_generation(
    "plugin.g2.dll"
);

if (plugin.abi_version == MORPH_ABI_V1) {
    host.active = plugin;
    // host_state keeps running
}
